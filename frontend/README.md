# frontend/ — Member 3 (Frontend & Visualization)

Dashboard that renders the API built by Member 2. Tabs: Overview, Granularity, Alerts,
Optimizer, Accuracy, Assistant, Settings. Use `contracts/sample/*.json` while the API is not
ready, then switch to the live API.

Rules from the PRD: colour-blind-safe palette, readable axis labels with units, an
"Advisory only" badge, loading and error states, local time shown with timezone.

Owner: Member 3. Work on branch `m3-frontend`. Do not edit `ml/` or `backend/`; ask in the
group chat (or a `contracts/` PR) if a field must change.
